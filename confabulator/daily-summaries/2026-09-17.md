### Why the agent could not be opened for two weeks

Not a Claude Code problem and not an extension problem.

- Cursor had been running **continuously since 2026-09-12 15:14**, 3 days 21 hours of uptime at the
  time of checking (pid 580).
- The Claude Code extension updated **five times underneath that live process**: 2.1.269 (09-12),
  2.1.270 (09-13), 2.1.272 and 2.1.273 (09-14). A running window loads the extension once at
  startup, so the live window was still holding what it loaded on 09-12.
- The extension's own log confirms it. Last activation line: **2026-09-14 11:19:42**, nothing since.
- The `cursor` shell command was **never installed**, which is why `cursor ~/projects/PA-AMZN` had
  no way to work.

Fixed the last one: symlinked `/Applications/Cursor.app/Contents/Resources/app/bin/cursor` into
`~/.local/bin/cursor` (already first on PATH). `cursor --version` returns 3.20.14. The stale
extension host still needs a **Developer: Reload Window** from William.

Also found but **not touched**: two CLI installs fighting. Homebrew cask 2.1.231 at
`/opt/homebrew/bin/claude` is shadowing npm global `@anthropic-ai/claude-code@2.1.250`, because both
want `/opt/homebrew/bin`. The CLI works, so this is cosmetic until it is not.
