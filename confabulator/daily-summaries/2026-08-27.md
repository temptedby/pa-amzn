## 2. The hourly engine works, and it exposed a one-way ratchet in Sponsored Brands

```
heartbeats today   13     (before yesterday: 1 or 2 a day)
```

But Sponsored Brands, the one ad type that makes money, had every keyword lowered seven times in a
single day.

```
                    moves   average bid
2026-08-24            36    $0.575
2026-08-25            52    $0.529
2026-08-26            40    $0.487
2026-08-27            91    $0.453     <- the day we went hourly
```

All 14 keywords, seven reductions each. Two reached the $0.10 minimum.

**Cause, traced to the line.** `planBids()` in `ad-rules.ts:1330` calls
`searchStep(base, since, undefined, ...)`. Passing `undefined` for `last` means:

- `inCooldown()` is never consulted, so `BID_COOLDOWN_HOURS` does not apply to Brands or Display
- `since` is month-to-date rather than since-the-last-change, so the same evidence is re-judged
  every run and produces the same verdict

Going hourly did not cause this. It multiplied it by 24.

**PR #6 does not fix it.** Verified three ways: state OPEN, head commit not an ancestor of main,
and `BID_COOLDOWN_HOURS` still reads 6 in the tree with zero `windowDays` references. Its diff
touches `bidWithMemory`, not `planBids`.

## 3. I recommended stopping the reductions. William pushed back and he was right

> *"We don't want to stop reducing the bids. Our ROAS is horrible this month. What's the

The defensible finding is narrower and it is about the other half of his own rule. `isSpending` is

## 4. The blind spot: three quarters of the account is never judged

`ad-engine.ts:710` loops over the **performance report** rather than the keyword list it has
already fetched in full:

```
for (const r of kt) { ... }      kt = report rows only
```

A keyword with no impressions produces no report row, so it never reaches the bid rule at all.

```
LIVE from Amazon    3,492 keywords    2,205 ENABLED
seen in August                          394
```

The rule for this case exists and is correct ("no impressions and no clicks, raising until it
enters the auction"). It simply never runs on them.

Note the money risk is **low**: a word is invisible because it is not spending, and the moment it
spends it appears and comes under the rules. What is lost is learning.
