## The review paid for itself

A high-effort review of the whole branch before merging found a **launch blocker**.

`perfSinceChange()` built its map by iterating recorded bid changes only. Every keyword without one
reached the bid logic as `undefined`, which reads as "no impressions and no clicks" and answers by
RAISING — and `isSpending`, reading the same missing object, computed false, disarming the guard
that stops a spending word being raised.

`kw_bid_history` had held **zero rows since creation** (the INSERT names `roas_before`, the table
declares `acos_before`, and the error was swallowed). So the first production run would have raised
**every enabled keyword on the account**, including words at $3.90 spent and 0.4x. The account-wide
version of the loop the PR was written to end.

Two more confirmed and fixed: the in-month revival read the wrong part of Amazon's response, so a
refused revive would still stamp `revived_at`; and the Display report never requested `impressions`,
so every target reported as "no impressions" whatever it had been shown.

**One finding I rejected.** The review argued a shown-but-never-clicked target should not be raised.
William decided otherwise on 08-10 — "yes it climbs if not spending or converting you raise the bid
to find the optimal" — so the code stays. My first test asserted the review's version and failed,
correctly, against his rule.

## A ceiling that recorded a number and changed nothing

Approving $3.50 on the branded head term, a test failed with `expected null to be 2.55`. `BID_CAP`
is $2.50 and the move clamps to it, so a keyword AT $2.50 could not move a cent. **The $2.85 gate
has been unreachable since the staircase was written.** The $2.85 approval applied twenty minutes
earlier would have done nothing at all.

Third instance today of the same shape: a rule that records intent and produces no behaviour, where
the record makes it look handled. The others were the `applied=1` flag and the empty bid history.

Cap now defers to the approved ceiling. Raises above $2.50 step a nickel, not a dime, on William's
call.

**And a correction I owe.** I told him "no ROAS yet" on both gated keywords and advised refusing
them, reading the current month only. Lifetime, `phone assured retractable phone tether` is
**$29.63 -> $273.18, 17 orders, 9.2x** — the best ratio in the account, with 2 clicks in 90 days.
Not failing. Barely in the auction. He was right.
